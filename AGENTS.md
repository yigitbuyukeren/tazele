# Tazele
- macOS SwiftPM güncelleme uygulaması. Gereksinimler `README.md`, plan `docs/PLAN.md` içinde.
- Arka planda yalnızca güncelleme kontrolü yapılır; kurulum kullanıcı onayı gerektirir.
- Doğrulama: `swift build && swift test`. Mevcut TR/EN yerelleştirmeyi koru.
- Yeni depo oluşturma veya uygulama dağıtımı açık kullanıcı isteği gerektirir. Diğer kurallar için kök `AGENTS.md` geçerlidir.
